# 🏭 Завод «MAG» — Офіційний веб-сайт та CMS Панель керування

Сучасний повнофункціональний корпоративний веб-сайт технічного заводу **«MAG»** з переробки зношених шин, пресування блочних гумових палет, монолітних плит та виробництва гумово-металевих виробів із впресованою сталлю.

Сайт розроблено виключно **українською мовою** згідно з усіма вимогами замовника, високим рівнем безпеки та зручною інтуїтивною панеллю адміністратора (CMS).

---

## 🌟 Ключові сторінки та можливості

### 1. 🏠 Головна сторінка (`/`)
* **Інтерактивна візуалізація та 3D-анімація на Canvas**: симуляція роботи гідравлічного преса 500 тонн, вулканізації гумового масиву, руху гумової крихти та магнітної сепарації корду, що реагує на курсор миші.
* **Індивідуальний фірмовий логотип MAG**: стилізація протекторного кільця шини та клину компресійного преса в індустріальних кольорах.
* **4 ключові виробничі напрями**: блочні гумові палети, пресування гуми зі сталевими вставками, надміцні плити, прийом та утилізація шин.
* **Каталог топ-товарів**: квадратні картки продукції з переходом до повної специфікації.
* **Банер індивідуального виготовлення**: замовлення нестандартних прес-форм за кресленнями.

### 2. 🏢 Про нас (`/about`)
* Повна історія заводу, виробничі потужності (15 000 т/рік, 4 800 м², преси 500 т).
* **5 етапів технологічного циклу**: Прийом -> Шредування -> Магнітна сепарація -> Впресування металу -> Гаряча вулканізація.
* Лабораторія якості, екологічна місія циркулярної економіки та офіційні сертифікати (ДСТУ ISO 9001:2015).
* **Фотогалерея цехів** із функцією збільшення фотографій (Lightbox).

### 3. 📦 Каталог товарів (`/catalog`)
* **Квадратні картки товарів** із якісним фото, категорією та назвою продукту під фотографією.
* Фільтрація за категоріями та живий пошук у реальному часі.
* **Окрема детальна сторінка товару (`/catalog/:slug`)**:
  * Велика галерея фотографій товару.
  * Повний інженерний опис та особливості застосування.
  * **Таблиця технічних характеристик** (розміри, вага, навантаження, тип сталевих вставок, твердість за Шором А, температура).
  * Кнопка прямого замовлення з автоматичним підставленням назви товару у форму запиту.

### 4. 📞 Зв'язатися з нами / Контакти (`/contacts`)
* Прямі контакти комерційного відділу та пункту прийому сировини (24/7).
* **Інтерактивна карта заводу**: карта на базі Leaflet із фірмовим маркером заводу MAG, навігацією Google Maps / Waze та точними координатами.
* Офіційні реквізити підприємства (ЄДРПОУ, ІПН, IBAN з ПДВ).
* Форма зворотного зв'язку з анти-спам захистом та сповіщеннями.

## ⚙️ Панель адміністратора (CMS) (`/admin`)

Інтуїтивний інтерфейс керування вмістом сайту без необхідності редагувати код:
* 🏠 **Головна**: зміна заголовків, текстів першого екрану, ключових цифр, описів послуг та банерів.
* 🏢 **Про нас**: редагування історії, місії, етапів технологічного процесу, списку сертифікатів та фотогалереї цехів.
* 📦 **Каталог товарів**:
  * Створення нових товарів із завантаженням головного фото та додаткових фотографій галереї.
  * Редагування назви, категорій, короткого та детального опису.
  * **Динамічний конструктор технічних характеристик** (додавання/видалення будь-яких параметрів: вага, навантаження, метал тощо).
  * Видалення товарів із підтвердженням.
* 📞 **Контакти**: зміна телефонів, електронної пошти, адреси, графіка, координат карти та банківських рахунків.
* ✉️ **Заявки клієнтів (CRM)**: перегляд усіх повідомлень та замовлень з сайту зі зміною статусу (Нова, В обробці, Завершена, Скасована).
* 🛡️ **Безпека**: зміна логіна та пароля, перегляд статусу захисту та журналу аудиту подій.

## 🔒 Захист сайту від кібератак

Реалізовано максимальний комплекс багаторівневого захисту:
1. **Helmet Security Headers**: сувора політика Content-Security-Policy (CSP), `X-Frame-Options: SAMEORIGIN` (захист від Clickjacking), `X-Content-Type-Options: nosniff`.
2. **Rate Limiting (Anti-Brute Force / Anti-DoS)**:
   * Автоматичне блокування IP-адреси при 5 невдалих спробах входу на 15 хвилин.
   * Ліміт на відправку форм контактів (максимум 10 запитів на годину з однієї IP).
   * Загальне обмеження частоти запитів до API.
3. **Хешування паролів**: алгоритм `Bcrypt` із 12 раундами солі.
4. **Захищені сесії**: `JWT` токени передаються виключно через захищені `HttpOnly`, `SameSite=Strict` Cookie, що унеможливлює крадіжку токена через XSS.
5. **Імунітет до SQL Injection**: використання виключно параметризованих підготовлених виразів (`prepared statements`) у базі даних SQLite.
6. **XSS Sanitization**: автоматичне очищення усіх вхідних полів через `sanitize-html`.
7. **Безпечне завантаження файлів (Multer)**:
   * Білий список виключно зображень (`image/jpeg`, `image/png`, `image/webp`, `image/svg+xml`).
   * Криптографічно безпечні випадкові назви файлів без можливості path traversal (`../../`).
   * Заборона виконання скриптів у папці завантажень (`uploads`).

## 🚀 Запуск проєкту

### Системні вимоги:
* Node.js v18 або вище (протестовано на v22)
* npm 9+

### Швидкий запуск у режимі розробки:
```bash
# 1. Встановити залежності (якщо не встановлено)
npm install
cd client && npm install && cd ..

# 2. Збірка клієнтської частини
npm run build

# 3. Запуск сервера (сервер віддає і API, і зібраний фронтенд)
npm start
```
Сайт відкриється за адресою: **`http://localhost:5000`**

Також доступна одночасна розробка з live-reload:
```bash
npm run dev
```
